# Student Performance Visualization System

A beginner-level Exploratory Data Analysis (EDA) project built using Python, Pandas, Matplotlib, and Seaborn to analyze and visualize student performance data.

---

## Features

* Handles missing/null values
* Calculates:

  * Total Marks
  * Percentage
  * Subject-wise averages
  * Class average
* Finds:

  * Topper student
  * Lowest scorer
  * Top scorers
* Generates visualizations using graphs

---

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn

---

## Visualizations Included

* Subject-wise average marks (Bar Chart)
* Student marks comparison (Bar Chart)
* Subject marks distribution (Pie Chart)
* Total marks distribution (Histogram)

---

## Dataset

The dataset is manually created using Pandas DataFrame and exported as a CSV file.
